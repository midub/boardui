# Contributing

Issues and pull requests are welcome.

- **Sign the CLA.** boardui is dual-licensed: AGPL-3.0 or a commercial licence
  ([LICENSING.md](LICENSING.md)). Pull requests can only be merged once their author has signed
  the [Contributor License Agreement](CLA.md), which lets both licences cover the contribution.
  CLA Assistant asks you to sign it on your first pull request.
- **Build and test** as described in [Building from source](README.md#building-from-source); CI
  runs the same checks. New features need tests and documentation.
- **Design changes** go through an [architecture decision record](docs/adr/README.md).
